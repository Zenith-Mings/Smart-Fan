智能风扇项目(实时监测温度，超过阈值风扇自启动，转速3档可调，数据可视化)，基于普中A2开发板，51单片机，STC89C52RC
# STC89C52 智能温控风扇项目

基于普中 A2 51 单片机开发板（STC89C52RC）实现的入门级智能风扇项目，支持实时温度监测、自动温控启停、按键调速、参数掉电保存等功能。

## 功能特性

- **实时温度采集**：通过 DS18B20 数字温度传感器采集环境温度，LCD1602 屏幕实时显示，分辨率 0.01℃
- **自动温控启停**：环境温度高于设定阈值时风扇自动启动，低于阈值自动停止
- **三档风速调节**：基于 PWM 脉冲宽度调制实现低 / 中 / 高三档风速，调速平滑稳定
- **按键参数设置**：
  - K1 键：升高温度设定阈值
  - K2 键：降低温度设定阈值
  - K3 键：循环切换风速档位
- **掉电参数保存**：温度阈值、风速档位存储在 AT24C02 EEPROM 中，断电重启后自动恢复
- **状态可视化**：LCD1602 同步显示当前温度、设定阈值、风速档位、超温提示

## 使用说明

### 1. 编译环境

- 推荐使用 **Keil uVision4 / uVision5** 进行编译
- 编译目标芯片选择 `STC89C52RC`，晶振频率配置为 11.0592MHz
- 编译后生成 `.hex` 格式烧录文件

### 2. 烧录程序

- 使用 **STC-ISP** 烧录工具
- 芯片型号选择 `STC89C52RC`，匹配实际晶振频率
- 连接开发板 USB 转串口，下载生成的 hex 文件

### 3. 操作说明

表格

| 按键 | 功能说明 | 参数范围 |
| --- | --- | --- |
| K1 | 温度设定阈值 +1℃ | 12℃ ~ 125℃ |
| K2 | 温度设定阈值 -1℃ | 12℃ ~ 125℃ |
| K3 | 循环切换风速档位 | 1 档（低速）→ 2 档（中速）→ 3 档（高速） |

### 4. 屏幕界面

```
// 第一行：当前温度 + 超温提示
T:+26.35  OV:H

// 第二行：设定阈值 + 风速档位
TH:28  Speed:2
```

- `OV:H`：当前温度超过设定阈值，风扇已启动
- 无`OV:H`：温度低于阈值，风扇停止

## 实现原理

### 温度采集

采用 DS18B20 单总线数字温度传感器，12 位分辨率，每 500ms 刷新一次温度数据。采用 “读取上次转换结果→发起下一次转换” 的流水线模式，无需主循环等待转换完成，提升系统响应性。

### PWM 调速原理

定时器 1 配置为 100μs 定时中断，维护 0~99 循环计数器，通过比较计数器与占空比阈值输出高低电平，生成 100Hz PWM 信号。通过改变占空比调节电机平均输入电压，实现平滑调速：

- 1 档：占空比 50%
- 2 档：占空比 75%
- 3 档：占空比 100%

### 参数存储

通过 I2C 总线驱动 AT24C02 EEPROM 芯片，将温度阈值和风速档位写入指定地址存储。上电时自动读取参数，参数非法时自动恢复默认值，保证系统可靠性。

## 常见问题

### Q1：温度不显示 / 显示乱码

1. 检查 DS18B20 是否插紧，引脚是否对应 P3.7
2. 确认开发板晶振为 11.0592MHz，与延时函数匹配
3. 检查定时器 1 是否正常启动，温度更新标志位是否正常置位

### Q2：风扇转一下停一下 / 转速不稳定

1. 检查定时器 1 中断函数中操作的是`TL1/TH1`寄存器，切勿与定时器 0 的`TL0/TH0`混淆
2. 确认`Counter`变量添加了`volatile`关键字，防止编译器优化异常
3. 检查电机驱动电路接线是否牢固

### Q3：断电后设置的参数丢失

1. 检查 AT24C02 芯片是否正常，I2C 引脚 SDA/SCL 是否对应
2. EEPROM 写入后需要至少 5ms 延时，确保写入完成

### Q4：按键无响应

1. 确认按键对应 IO 口与代码中定义一致
2. 检查按键消抖延时是否合适，可适当调整消抖时间
